# 朱雀相关启发式

本文件只保留“平台风险启发式”，不再把这些内容视为严格检测标准。

---

## 使用原则

- 只能作为弱信号参考
- 不能单独用来判断作者身份
- 不能承诺“照着改就一定通过”
- 必须结合文本类型、长度和是否存在引用/代码/清单内容

---

## 一、连接词密度检测

### 可能引发风险的连接词模式

| 类别 | 连接词 | 检测规则 |
|------|--------|----------|
| **结构连接词** | 首先、其次、再次、然后、此外、总之、总而言之 | 如果全文高度依赖，可能增加模板感 |
| **转折连接词** | 然而、但是、其实、实际上 | 高频重复时可视为弱信号 |
| **补充连接词** | 还有啊、其实啊、值得注意的是 | 和全文模板感一起出现时才有意义 |
| **时态连接词** | 随着、发展、在...时代、在...今天 | 开篇宏大铺陈可能显得空泛 |
| **总结连接词** | 综上所述、由此可见、可以说 | 结尾过度总结时可视为弱信号 |

### 检测示例

**AI 特征文本**：
```
随着人工智能技术的发展，各行各业都在经历变革。
首先，医疗领域引入了 AI 诊断系统。
其次，教育行业也开始使用智能教学。
此外，金融行业的风控也离不开 AI。
总之，AI 正在改变我们的生活。
```

**人味文本**：
```
AI 这玩意儿现在真是无处不在了。
医院里用它看片子，学校用它讲课，连银行风控都靠它。
说真的，有时候都觉得离了 AI 日子都没法过了。
```

## 二、序号和列表检测

### 常见形式

- 中文序号：一、二、三、四...
- 阿拉伯数字：1. 2. 3. 4....
- 字母序号：A. B. C. D....
- 符号列表：- * •

### 使用提醒

序号和列表在说明文、文档、教程里非常常见，不能单独作为 AI 证据。

**较模板化写法**：
```
选择产品时要注意以下几点：
一、品牌知名度
二、产品质量
三、售后服务
```

**更自然的表达**：
```
选产品这事儿，我一般先看牌子，大厂的东西起码有保障。
然后看看质量怎么样，用料足不足。
最后还得瞅瞅售后，坏了能找到人修。
```

---

## 三、括号使用说明检测

### 常见形式

- 圆括号：（说明内容）
- 方括号：[补充信息]
- 六角括号：〔注释〕

### 使用提醒

括号在正式说明、注释、译注中很常见，只能作为弱信号。

**较模板化写法**：
```
这款产品（尤其是粉色版本）非常受欢迎，销量（截至上个月）已经突破百万。
```

**更自然的表达**：
```
这款产品粉色的那个版本卖得特别好，到上个月销量已经破百万了。
```

---

## 四、破折号使用检测

### 检测特征

频繁使用破折号进行补充说明：

```
这个功能——正如我们之前提到的——代表了技术进步。
结果——出乎所有人意料——非常好。
```

### 使用提醒

破折号频繁出现可能让文本显得“修辞化”，但不能单独用于判断 AI。

---

## 五、段落结尾标点检测

### 常见观察

| 写作类型 | 段落结尾特征 |
|----------|--------------|
| 较随意写作 | 段落结尾可能不统一 |
| 较正式写作 | 段落结尾往往更统一 |

### 使用提醒

段落结尾标点高度统一，更可能说明文体正式，不足以证明 AI。

---

## 六、段落规整度检测

### 可能的模板感信号

- 段落长度均匀（每段 80-120 字）
- 每段都有主题句和总结句
- 段落之间过渡平稳

### 可能的自然写作信号

- 段落长短不一
- 有超长段落（300+ 字）
- 有超短段落（一句话成段）
- 段落之间跳跃较大

---

## 更稳妥的自然化方向

### 1. 思维过程真实化

可以增加：

- "对了，还有个事情想说..."
- "写到这突然想起来..."
- "其实我之前也纠结过这个问题"
- 在某处提出问题后自己回答

### 2. 降低过度抛光感

- 段落长短不一
- 口语化表达和不太规范的句子
- 某些观点可能会多说几句，而不是面面俱到
- 用自然的方式过渡，而不是明显的结构词

### 3. 让判断更具体

- 加入自己的情感和看法，有时甚至有点主观
- 和读者互动，问问题，引发思考
- 该感叹时就感叹，但不要太夸张
- 整体看起来随性自然

### 4. 视角更明确

| 场景 | 使用人称 |
|------|----------|
| 讲述个人经历 | "我" |
| 分享共同经验 | "我们" |
| 直接对读者建议 | "你" |
| 讨论普遍现象 | 第三人称 |

## 朱雀风险分析模板

### 输出格式

```
## 朱雀专项检测

### 平台风险信号：高/中/低
检测到的连接词：
- "首先"（第 2 段）
- "其次"（第 3 段）
- "总之"（最后一段）

### 结构规整度：高/中/低
- 发现序号列表：3 处
- 段落长度均匀度：过高

### 括号使用：X 处
- （尤其是粉色版本）- 第 1 段
- （截至上个月）- 第 2 段

### 破折号使用：X 处
- 第 3 段使用 2 处破折号

### 段落结尾标点：全部使用/部分使用/基本不用

### 误判风险：高/中/低
- 个人经历：无
- 情感表达：较少
- 口语化：较少
```

## 改写建议模板

### 针对连接词过多的自然化示例
```
原文：首先，我们需要了解产品的基本功能。其次，要考虑价格因素。最后，还要看售后服务。
改写：选产品嘛，得先看看基本功能怎么样，价格能不能接受，售后也得考虑考虑。
```

### 针对序号列表的自然化示例
```
原文：
选择产品要注意：
一、品牌
二、质量
三、价格
改写：选产品这事儿，牌子、质量、价格都得看，一个都不能少。
```

### 针对括号说明的自然化示例
```
原文：这款产品（尤其是新版本）非常受欢迎（销量已破百万）。
改写：这款产品的新版本卖得特别好，销量已经破百万了。
```

## 使用提醒

- 这些启发式只能增加或降低“模板化风险”判断
- 它们不能单独证明 AI 作者身份
- 技术文档、教程、公告类文本尤其容易误伤
