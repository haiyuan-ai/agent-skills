# AI Vibe Detector

分析文本中的 AI 风格信号、AI 润色痕迹、误判风险，并提供自然化改写建议。

## 这个 skill 做什么

- 判断一段文本是否带有明显的模板化 AI 风格
- 区分“更像 AI 原生风格”与“更像 AI 润色痕迹”
- 提醒哪些检测结论容易误判
- 给出去模板感、保留原意的改写方向

它不做的事：

- 不保证通过任何 AI 检测器
- 不承诺“证明一定是 AI 写的”或“一定是人写的”
- 不把平台启发式当成硬规则
- 不提供面向特定检测器的定向规避建议

## 触发方式

适用于这类请求：

```text
检查 AI 味
这段像 AI 写的吗
帮我去 AI 味
看下朱雀风险高不高
改得更像人写的
```

## 输出方式

默认输出：

```text
结论：更像人工原生写作 / 更像 AI 风格化写作 / 更像 AI 润色痕迹 / 证据不足
置信度：低 / 中 / 高
误判风险：低 / 中 / 高

主要依据：
1. ...
2. ...

反误判因素：
1. ...

改写建议：
- ...
```

如果用户明确要分数，可以附加 `AI 风格风险 0-10`，但分数不能单独使用。

## 分析框架

### 1. 高置信结构信号

- 模板化结构反复出现
- 段落和句式过于均匀
- 收束句、总结句太稳定
- 整篇像“完整标准答案”

### 2. 中置信语言信号

- 连接词偏多
- 抽象名词多，细节少
- 情绪和判断过稳
- 同义改写很多，但信息增量很少

### 3. 低置信平台启发式

这些只能当弱信号：

- 序号、列表
- 括号、破折号
- 段末标点一致
- 某些高频连接词

### 4. 反误判保护

分析前先排除这些高误判场景：

- 技术文档 / FAQ / 操作说明
- 学术文 / 公文 / 公告
- 引用、代码、命令、表格
- Prompt 指令，不是正文
- 人写后被 AI 轻度润色

## 朱雀和类似检测器

如果用户提到朱雀或类似检测器，这个 skill 会额外分析：

- 哪些结构可能提高“模板化”风险
- 哪些地方其实容易被误判
- 哪些改写是“更自然”，而不是“更会躲”

这里的原则是：

- 平台规则只能当启发式
- 不能当作者身份证明
- 不能承诺“这样改就一定过”
- 不做“针对某个平台怎么改最容易过”的专项优化
